# Oracle TPs & TDs

Coursework repository for an Oracle Database module, covering SQL and PL/SQL fundamentals through a series of guided tutorials (**TD** — *Travaux Dirigés*) and hands-on lab exercises (**TP** — *Travaux Pratiques*).

## 📚 Overview

This repository contains SQL scripts, PL/SQL code, and exercise solutions written and tested on **Oracle Database**. It documents intensive, hands-on practice with relational database concepts — from core SQL querying to more advanced server-side logic.

## 🗂️ Repository Structure

| Folder | Topic |
|---|---|
| `td1` | Tutorial exercises — Part 1 |
| `td2` | Tutorial exercises — Part 2 |
| `td3` | Tutorial exercises — Part 3 |
| `td4` | Tutorial exercises — Part 4 |
| `tp1_oltp+olap` | OLTP vs. OLAP — transactional vs. analytical query design |
| `tp2_views` | SQL views — creation, usage, and updatable views |
| `tp3_triggers` | PL/SQL triggers — automated actions on data events |
| `tp4_bdro` | Advanced Oracle database concepts |

Each folder contains the SQL/PL-SQL scripts and exercise solutions for that session.

## 🛠️ Tech Stack

- **Database:** Oracle Database
- **Languages:** SQL, PL/SQL
- **Tools:** Oracle SQL Developer / SQL*Plus

## 🎯 Topics Covered

- Writing and optimizing SQL queries
- OLTP vs. OLAP query patterns
- Views (simple, complex, updatable)
- Triggers and event-driven logic in PL/SQL
- Relational database design and manipulation in Oracle

## ▶️ How to Run

1. Set up a local or remote Oracle Database instance (e.g., Oracle XE, or access via your institution's server).
2. Open the desired script in **Oracle SQL Developer** or connect via **SQL\*Plus**.
3. Run the `.sql` files in order within each folder to reproduce the exercises.
